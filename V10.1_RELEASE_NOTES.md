# V10.1 — "A fairer fight, a safer match"

File: `(V9.9) australia-game-with-ai.tsx` (still one self-contained file, default export, React only). Version label V10.1 (`GAME_VERSION` 10.1.0). New code is in Sections 20BA–20BK, before Section 21. Full findings and the deferred list: `V10.1_DIAGNOSIS.md`.

## Changelog for players

* **Money you can trust.** Buying from the Resource Market now costs about what the same goods sell for, so buy-and-resell in one region no longer prints cash. Bulk buys nudge the price up a little. (New matches.)
* **Challenges are a decision.** Odds top out at 85%, pay trims as odds climb, and every challenge you take tires you a little. Every challenge card shows the win, the loss and the average in dollars. (New matches.)
* **A rival that is what its label says.** It pays the same fares and picks from the same challenge board as you, and selling no longer costs it an action. Harder rivals plan journeys and rank challenges by what a win really pays, so Medium, Hard and Expert play stronger than before. Turn on **Rival Recap** to see what it did on its turn and why.
* **Match rules stay put.** While a match runs, Victory Goal, Game Length and Difficulty are locked; changes wait for your next match. Team bankruptcy tests the cash its warnings name, sabotage lasts what it says, replays are finalised, and a Single Player run ends with a graded RUN COMPLETE. (New matches.)
* **A safer first hour.** The menu says plainly how saving works; the tutorial answers the Ask chips on the Play screen; starting from a Journal seed or loading a file asks before it replaces your autosaved match; a one-time Guided Learning lesson offers Autosave.
* **The world tells the truth.** Infrastructure, contracts and faction advice appear only when switched on; Fund now lets you pick an amount; faction rewards say what they do; "day" means day.
* **Advice you can trust.** Ask the Game AI answers from your real match, the Play card names one best move, the Strategy Planner plans real actions.
* **More to play for.** With External Territories on, the territories have their own challenges; objectives complete; every challenge counts in Most challenge points; story choices keep consequences; the optional **Daily Challenge** (needs the Match Journal) fixes the rules so scores compare day to day.
* **Easier to use.** Strategy Planner opens and closes properly; the More menu stays on screen; shortcuts follow their buttons; Escape works from any field; main windows are real dialogs; Light theme readable; text size A-/A+; a banner appears if the game styles fail to load.
* **Settings that do what they say.** Presets always visible; Start Collapsed and Remember work; the Co-Pilot turn limit follows actions per day; applying a preset shows what changes and keeps personal preferences.
* **Under the hood.** Replays and self-test buttons no longer disturb a live match; a recovery banner offers a backup copy if something breaks; AI vs AI no longer runs the player advisor.
* **Want the old balance?** Settings → New in V10.1 → *Classic rules (V10.0)* starts new matches by the V10.0 rules. Older saves always keep the rules they were started with.

## Technical note

**Compatibility.** Matches carry `rulesVersion`: V10.1 = 1010, V10.0 = 1000, older = none. Every behaviour change is gated by `isV101Match`. Saves are migrated by a new rung (`migrateSaveTo1010`); the three new match-state keys (`purchasePressure`, `rivalRecap`, `dailyChallenge`) are sanitised on load and stripped from pre-10.1 saves. 34 real V9.6–V10.0 saves load intact; 279 hostile variants never throw; 81 classic-rules matches equal V10.0 to the dollar. New settings, all **off** by default and no existing default changed: `rivalRecapEnabled` (profile), `dailyFixedRulesEnabled` (match), `classicRulesV100` (match). Randomness uses the seeded RNG; the Rival Recap has its own cosmetic stream. No `Math.random` in game logic; no new dependencies.

**Judgement calls you should know about**
1. The balance and rule fixes are **on by default for new matches** (stamped 1010); the opt-out is *Classic rules (V10.0)*. The brief says new features are off by default; I treated the broken economy as a fix, not a feature. If you want the opposite default, flip the stamp choice at match start (one place) — nothing else changes.
2. Autosave defaults are unchanged; the nudge is a one-time Guided Learning lesson.
3. Classic matches differ from V10.0 only in advisor/helper text and some hash ids.

**Known gaps** (details in `V10.1_DIAGNOSIS.md`): Hard/Expert still lean easy for the Tourist and the characters are unbalanced (Tourist ≫ Scientist); measured fix is a Tourist pay x1.1 plus a Scientist odds perk, not shipped. Recommended-only play still reaches about $75k grade S on Easy. A rule edit held by the live lock is lost on reload (visible, not silent).

**Risks**
* The pay curve is a real nerf; expect the first feedback to be "challenges pay less".
* Text size scales the page's root font size; check any hard-coded px layouts.
* The Strategy Planner was never mounted before; this is its first real exposure.
* Co-Pilot cap uses a "touched" flag in localStorage.
* Rival turns take 8–10 s per day in the browser; unchanged by design but the new journey scoring was not timed.

**Test by hand**
1. New match on Easy: play 3 days; check challenge cards show dollars, Market buy price ≈ sell price, a refused buy shows an inline message.
2. Open Settings mid-match: Victory Goal / Game Length / Difficulty are locked with a reason; changing one says "next match".
3. Load a V9.8 save and a V10.0 save: they resume with their old rules (no locks, old market).
4. Classic rules switch on → new match plays like V10.0.
5. Rival Recap on; Daily (with Match Journal on): HUD shows 20 days / Most Controlled Regions on a Daily card.
6. Open More at 1280 px and on a phone: panel on screen; Escape from a text field; Tab stays inside dialogs.
7. Light theme and text size A+ on the Play screen.
8. Block `cdn.tailwindcss.com` and confirm the plain banner appears.

**Not exercised in a browser:** pixel-exact look with the real Tailwind CDN (blocked in the sandbox; tested with locally built Tailwind 3.4.17), Retro theme, Fast/Instant pace, Nation/Full modes, replay recording, real touch input, and a full Daily/Recap match.
