# V11.0 UX Map — "Find Anything" round, package UX-1

Audit of `(V10.1) australia-game-with-ai.tsx` (282,211 lines, md5 `a7d56ae0e89666564909bacaaa7370df`). **No code was changed.** Every number below was read from the file's own registries or measured by driving the real game in Chromium; nothing is estimated unless it says *derived*. This map is the input for UX-2 to UX-6 and for the test that walks it.

## At a glance

- **Surfaces.** Of the 61 registry surfaces, 16 open in one click from the play screen and 9 more in two (measured); the rest are always on screen (the play view, HUD, quick bar, toasts), appear only after a switch or an event, or never open: **8 ids have no opener at all** (§11.1) and **5 ids are shared by two different windows** (§12.1). **28 real windows and panels have no id** (§5), so the surface manager, Escape and the rescue cannot see them.
- **Settings navigation.** *More › ⚙️ Settings* opens the **Simple** view (22 choices). The hub is one more click; its tabs are 2 clicks away through a ⋯ More shortcut or a LAB card, except **Economy & Money and Competition & Regions, which take 4**.
- **Settings you cannot find.** The game's own settings search (`searchSettingsHub`, run for every key) finds 570 of 599; the **29 it cannot find** are the keys missing from the hub index — 12 of the 13 national-system switches and 7 replay switches that are on screen in other sections, the Team OS switches in LAB and the Guided Learning choices in INTELLIGENCE (§11.5).
- **Settings you cannot change.** 45 indexed settings have **no control anywhere** and 5 only a reset touches (§11.3); 18 have their control somewhere other than where search sends you — the Guardian AI Center window, the Activity Ledger window or another section (§11.4).
- **Duplicates.** 15 settings are indexed in more than one section; the 22 Simple-view settings each have a second control in the hub; ⋯ More and *View All Actions* open the same popover; *More › 🎬 Replay* opens replay **settings**, not the Replay Studio (§12).
- **Shortcuts.** 17 shortcut groups; **Ctrl+K is already taken** by the optional Ask the Game AI drawer (Q5); an Alt+S Strategy Planner hotkey exists but is never wired.
- **The brief's numbers** all match the file except the self-test baseline (Q1). Eight questions for you are in §13.

## 1. How to read this map

**Starting point for every click count:** a fresh browser, the guided first match skipped with *Skip tutorial — open the full game* (not counted), V10.1 defaults, an AI Opponent match on the **PLAY** layer, 1280×800. A click is one press; scrolling and typing are not clicks. Keyboard alternatives are listed separately.

- **measured** — the path was replayed from a fresh page in Chromium and the game's own surface manager (`window.__GLOBAL_UI_SURFACE_MANAGER__`) or UI state confirmed the result.
- **derived** — computed from the code (the opener's conditions) plus a measured base path, because the default state hides it (e.g. a feature that is off).
- **Moves in** names the package that changes the item's home. Every row also gets a Find Anything entry in **UX-2**; that is not repeated per row. **UX-6** restyles everything and adds the classic switch that restores the V10.1 home shown in the *today* column.
- **V11.0 group** is the proposed UX-3 home: ⭐ Essentials · 🎮 Match & rules · 🤖 Your rival · 👥 Teams & automation · 🧭 Help, screen & sound · 🔬 Records & tools.
- **ids are the contract.** The UX-2+ walk test should iterate the ids in sections 4–10 and assert each is still reachable; ids never change in this round.

- **Browser runs** (Chromium, the real game via Vite, Tailwind 3.4.17 built locally because the CDN is unreachable from the sandbox): a breadth-first click crawl from the play screen (48 one-click and 358 two-click paths, each replayed from a fresh page, reading `window.__GLOBAL_UI_SURFACE_MANAGER__` and the game's UI state); a settings probe that flipped 1479 controls in the hub (advanced and basic views with defaults, and the advanced view with the 51 gating switches on) and recorded which key each one wrote, restoring the setting after each (212 distinct keys got a working control; a control that changed nothing is never taken as proof of a missing control — the "no control" verdicts in §11.3 rest on the code scans); a path check of all 11 tabs and every LAB card; 24 targeted scenarios (a switch turned on, then the path clicked). Clicks that change the match (Do It, End Turn, travel, buy/sell, loans, Leave) were never used as steps except Leave for the menu route.
